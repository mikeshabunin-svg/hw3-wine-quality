# Подборка хороших вин

Учебный проект по логистической регрессии на данных Wine Quality. Модель оценивает, получит ли вино оценку не ниже 7, по его физико-химическим характеристикам.

[Открыть приложение](https://hw3-wine-quality-utcyuzy9wcm3ygvhgurizx.streamlit.app)

## Что есть в приложении

На вкладке «Оценка одного вина» можно ввести характеристики образца и увидеть вероятность того, что вино хорошее. Начальные значения и диапазоны полей взяты из тестовых данных.

Во вкладке «Модельные метрики» показаны матрица ошибок, precision, recall, F1, ROC- и PR-кривые. Ползунок слева меняет порог рекомендации сразу во всём приложении. Чем ниже порог, тем больше вин попадёт в подборку, но тем больше среди них может оказаться посредственных.

Во вкладке «Пакетное предсказание» можно загрузить CSV с несколькими винами и скачать результат. Там же есть пример файла. Если в данных не хватает столбцов или есть некорректные значения, приложение покажет сообщение об ошибке.

Вкладка «Что выучила модель» показывает коэффициенты регрессии: какие признаки повышают оценку модели, а какие понижают.

## Как запустить локально

Приложение проверено на **Python 3.14.0**. Скачайте репозиторий и откройте терминал в папке, где лежит `app.py`.

Создайте окружение, установите зависимости и запустите Streamlit:

```bash
python3.14 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

После запуска откройте адрес из терминала — обычно это http://localhost:8501.

Модель уже обучена в ноутбуке. Приложение загружает её из `model.joblib` и использует для предсказаний. Начальный порог берётся из `config.json`; он выбран на валидационной выборке по F1 и равен примерно **0.269**.

## Как подготовить CSV

Файл должен содержать 12 столбцов:

```text
fixed_acidity, volatile_acidity, citric_acid, residual_sugar,
chlorides, free_sulfur_dioxide, total_sulfur_dioxide,
density, pH, sulphates, alcohol, is_red
```

Все значения должны быть числовыми, без пропусков. В `is_red` укажите **0 для белого вина** или **1 для красного**. Столбец `target` добавлять не нужно. Разделитель столбцов — запятая, десятичный разделитель — точка. Порядок столбцов может быть любым.

В скачанном результате появятся вероятность `probability`, класс `prediction` и рекомендация `recommendation`.

## Как устроено кэширование

Streamlit запускает скрипт заново при каждом действии пользователя. Чтобы каждый раз не читать модель с диска, функция `load_model` использует `st.cache_resource`. Так один загруженный объект модели можно использовать между запусками и пользовательскими сеансами.

Для таблиц и рассчитанных вероятностей используется `st.cache_data`: он хранит результаты вычислений и возвращает их копии. Вероятности на тестовой выборке не зависят от порога, поэтому при движении ползунка заново считаются только классы и метрики. Аргумент `_model` исключён из хеширования, а таблица признаков учитывается в ключе кэша.

Без кэширования `joblib.load` загружал бы модель при каждом изменении полей или порога. Если заменить файл модели, нужно перезапустить приложение или очистить кэш.

## Что лежит в репозитории

- `HW3_MMDA.ipynb` — решение домашнего задания, части 1–4.
- `wine_quality.csv` — исходные данные для ноутбука.
- `app.py` — приложение на Streamlit.
- `model.joblib`, `config.json`, `test.csv` — обученный пайплайн, выбранный порог и тестовая выборка.
- `requirements.txt` — версии библиотек для приложения.
- `wine_app.zip` — архив приложения для сдачи.

Для выполнения ноутбука дополнительно понадобятся `seaborn` и `imbalanced-learn`. Файл `wine_quality.csv` должен лежать рядом с ноутбуком.
